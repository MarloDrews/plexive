# Mental thumbnail artwork

The 3D renders the `mental` generator composites. Loaded by
`app/thumbnails/figures.py`; nothing here is generated by code.

## Layout

One folder per camera angle, three PNGs in each:

```
assets/mental/
  angles.json          {folder: "one line saying what the camera sees"}
  profile/
    head.png           the solid head
    brain.png          the brain alone
    head_glass.png     the same head as a translucent shell
  three-quarter/
    ...
```

A single-angle set may put the three PNGs directly in `assets/mental/` instead;
that angle is then called `default`.

## Export rules

1. **Transparent background.** In Blender: Render Properties > Film >
   Transparent. A layer exported on white still loads -- its backdrop is keyed
   out -- but the edge is worse, and `head_glass.png` cannot be rescued that way
   at all, because it is near-white by design.
2. **One camera, one resolution, no cropping.** `brain.png` and
   `head_glass.png` must come from the *same* camera at the *same* frame size,
   with the brain left where it sits inside the head. That is what makes the
   `brain_in_head` motif line up: the loader stacks the full frames and crops
   once, afterwards. Cropping a layer by hand in an image editor breaks it.
3. **Colour does not matter.** Every layer is recoloured into the card's
   palette from its luminance, so a grey head and a pink brain both come out
   the same red, blue, green or yellow. Render with even, readable shading; the
   hue is thrown away.
4. Roughly 1920x1080 is plenty -- the card is 1280x720 and the figure fills
   about two thirds of it.

## Adding an angle

Drop the folder in, name it in `angles.json`, and regenerate the doc:

```
python backend/scripts/thumbnail_catalog.py --write-doc
```

The new angle appears in the generator's `angle` parameter, in
`docs/content-structure/THUMBNAIL_GENERATORS.md` and in the prompt that picks a
thumbnail for a post. No code changes.
