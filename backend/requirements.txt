# CI has to mirror what ships. Nothing here was an upgrade when this file was
# written: where production ran an older version than the laptop, production won.
#
# Six lines are now AHEAD of that freeze, moved by the 2026-08 security batch to
# clear published advisories: Pillow 12.3.0, starlette 1.3.1, pyasn1 0.6.4,
# cryptography 50.0.1, h2 4.4.1 and hpack 4.2.0. Until someone runs
# `pip install -r requirements.txt` on the Pi, production still serves the old six
# and this file is the target rather than the mirror. Everything else still comes
# from the freeze.
#
# Why this file exists at all: unpinned, CI resolved fastapi 0.141.1 on the same
# commit the Pi runs 0.136.3, and the two disagree on behaviour (len(app.routes)
# is 23 against 57). The boot guard counted routes at the time, against a floor of
# 20, so it survived that by three on luck. It counts OpenAPI paths now, but the
# drift it was reacting to is what this file removes.
#
# To regenerate: create a clean virtual environment on Python 3.13, install this
# file, run `pip freeze`, and reconcile the result against the blocks below. Keep
# the split. It is the only thing that still records what this backend actually
# depends on, as opposed to what pip happened to pull in behind it.
#
# There is deliberately no pip-tools, uv, poetry or lockfile here. Those are
# structurally better, and they add a workflow step for everyone who touches the
# backend, including a collaborator who is not a developer.

# --- Not installable on Windows ---
# A platform condition, NOT an optional dependency. uvloop publishes no Windows
# wheel at the pinned version (checked against PyPI: sdist only) and its build
# refuses to run there, so an unconditional
# pin makes `pip install -r requirements.txt` fail outright on the Windows dev
# machine -- and a file that cannot be installed where development happens is a
# file that gets worked around, at which point the pinning is worth nothing.
#
# uvicorn[standard] carries this same condition internally; naming uvloop here to
# pin it discards that, so it has to be restated. Linux (the Pi, CI) and macOS all
# install it; only Windows skips it.
#
# Do not delete this line. The marker means "not available on this platform", not
# "we are not sure we need it".
uvloop==0.22.1 ; sys_platform != "win32"
