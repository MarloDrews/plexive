# pip-audit==2.10.1 WAS HERE AND WAS REMOVED ON 2026-08-31. This paragraph is the
# record, because a line that is simply deleted gets added back by the next person
# who notices there is no dependency scanner.
#
# WHAT IT WAS DOING: nothing. It was pinned here from 2026-08-27, which meant CI
# installed it -- and its ~19 unpinned transitive packages -- on every single run,
# and no workflow ever called it. The comment above it said "run before a release"
# and nothing did. It was the sharpest instance in this repository of a tool that
# is configured and never consequential.
#
# THE CHOICE WAS INVOKE IT OR REMOVE IT, and it was removed, for three reasons:
#
#   1. This repository already decided that security scanners are not merge gates,
#      and said so in .github/workflows/codeql.yml:3-8: "a security finding is a
#      thing to triage, not a thing to block a merge on". CodeQL runs on every
#      pull request and is deliberately absent from the ruleset. Wiring pip-audit
#      into a required check would reverse that policy for one scanner while
#      leaving it in force for the other.
#   2. pip-audit fetches advisory data at run time, so invoking it puts a
#      third-party network call inside a required check. That is the same reason
#      lint's NewerVersionAvailable and AndroidGradlePluginVersion detectors are
#      disabled in mobile-kmp/androidApp/build.gradle.kts: a gate that can go red
#      or go slow on a day nobody touched this repository is a gate that gets
#      switched off.
#   3. Dependabot SECURITY updates are on repository-wide and cover
#      backend/requirements.txt. docs/CI_NOTES.md already calls them "the
#      automatic half". That is the automation; this was not.
#
# WHAT WAS GIVEN UP, stated rather than glossed: PyPI/OSV as a second advisory
# source alongside GitHub's, and the recorded 2.10.1 pin. The accepted ecdsa
# PYSEC-2026-1325 / CVE-2024-23342 finding is NOT lost -- requirements.txt carries
# both reasons it does not reach this codebase, next to the python-jose pin that
# pulls ecdsa in.
#
# To run it by hand, from backend/, without putting it back in this file:
#   python -m pip install pip-audit && python -m pip_audit -r requirements.txt
